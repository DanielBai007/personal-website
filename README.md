# 🏠 个人站 - 讲次评价分析平台

> 一个集成了讲次评价分析功能的现代化个人站点

## ⚡ 快速开始

```bash
# 1. 安装依赖
npm install

# 2. 启动项目（推荐）
./启动.sh
# 选择 1) 启动个人站展示

# 3. 体验功能
# 浏览器自动打开 http://localhost:3000/portfolio
# 点击 "讲次评价分析平台" 即可体验完整的数据分析功能
```

### 常见问题
**Q: 为什么不能自动上传数据？**
A: 由于浏览器安全限制，我们无法直接操作外部网站。系统会预加载数据并提供使用指导。

**Q: 数据加载很慢怎么办？**
A: 可以点击"直接进入"跳过加载，或等待预加载完成（首次约需10-15秒）。

**Q: 如何查看演示数据分析？**
A: 进入平台后，点击"上传数据" → 选择预置的CSV文件 → 点击"分析数据"即可。

**Q: 在移动设备上体验如何？**
A: 支持响应式设计，但建议在桌面端获得最佳分析体验。

### 使用技巧
1. **快速体验**: 点击"直接进入"立即访问平台
2. **数据准备**: 系统已预加载13MB演示数据
3. **操作流程**: 上传数据 → 分析数据 → 查看结果
4. **功能探索**: 尝试筛选、导出等高级功能
